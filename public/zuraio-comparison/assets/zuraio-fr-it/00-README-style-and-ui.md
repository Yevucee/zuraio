# Zuraio FR + IT copy: how to use these files

Files 01 to 08 contain `fr:` and `it:` blocks that mirror the existing `en:` blocks key for key. Paste them next to `en`/`de` in the matching copy module. File 02 Part B holds the three invented documents for the Skills tabs.

## Voice and conventions (keep these when anything is added later)

| | French (Suisse romande) | Italian (Svizzera italiana) |
|---|---|---|
| Address | **vous** throughout | **voi** for the company/team (site-wide); **Lei** only inside the tenant letter and the hero email, where one person writes to one person |
| Buttons | infinitive or imperative: «Réserver une démo» | infinitive: «Prenotare una demo» |
| AG / GmbH | **SA** / **Sàrl** (Muster SA, Exemple Sàrl) | **SA** / **Sagl** (Muster SA, Esempio Sagl) |
| Numbers | CHF 8'400 (Swiss apostrophe), 5 %, 2,4 | CHF 8'400, 5 %, 2,4 |
| Dates | 30 septembre, jeudi 8 octobre | 30 settembre, giovedì 8 ottobre |
| Quotes | «…» without inner spaces | «…» |
| Punctuation | Swiss romand usage: non-breaking space before **:** («Utilise :»), no space before **; ? !** | standard Italian |
| Apostrophe | typographic ’ | typographic ’ |
| Dashes | none (dash guard applies) | none |
