Deployment

Local, hybrid or Swiss-hosted.

Different companies have different requirements for data location, infrastructure, model choice, operations and cost. Zuraio supports deployment designs that can be adapted to those requirements.

The availability of a specific model must be confirmed as part of the technical and commercial scope.

Three models

Local, hybrid and Swiss-hosted options.

Available by project — confirm scope

Local or customer-controlled

Selected Zuraio components, assistants or models can be designed to run in customer-controlled infrastructure or a private cloud.

  • Greater control over processing and storage locations
  • Suitable for selected confidential or internally governed workloads
  • Can use local models and approved cloud models according to policy
  • Requires additional customer IT involvement
  • Operational responsibility must be agreed

Local deployment is not a single standard package. Component availability, hardware, support, updates, backups and model requirements must be confirmed for each project.

Available by architecture — confirm components

Hybrid

A hybrid design can place different data sources, assistants and models in different approved environments while coordinating them through a shared control layer.

  • Sensitive knowledge can remain in customer-controlled systems
  • Selected processing can take place in approved managed environments
  • Model choice can vary by task and data classification
  • Individual assistants can operate close to the systems they use
  • Data flows and responsibilities must be documented
Hosting option — commercial and technical scope required

Swiss-hosted

For companies with Swiss data-location requirements, selected Zuraio components and suitable models can be designed to operate in a Swiss server environment.

  • Swiss processing and storage options for agreed components
  • Reduced internal infrastructure burden compared with fully local operation
  • Configurable permissions and model policies
  • Can form part of a wider hybrid architecture
  • Subject to agreed providers, services and contract terms

The exact operator, locations, model providers, subprocessors and data flows must be documented for the selected offer.
